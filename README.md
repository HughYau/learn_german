# DailyGerman

> 日常德语，一站就够了。

一款面向中文学习者的开源德语学习网站，从零基础出发，围绕真实生活场景覆盖 A1–B1 的课程、词汇和听说读写练习。

🌐 **在线学习：** [https://hughyau.com/learn_german/](https://hughyau.com/learn_german/)

## 你可以学什么

- 34 个场景单元、64 节渐进课程
- 740 张课程词卡与间隔重复复习
- 语法手册、实用短语和生活任务
- A1–B1 听力材料与阅读练习
- 每日学习计划、进度记录和数据备份
- 浏览器德语朗读与可选 AI 陪练

## 开始使用

在线版本发布后，直接打开上方网站即可学习，无需注册。学习进度保存在当前浏览器中，也可以在设置页导出备份。

本地运行：

```bash
python3 server.py
```

然后打开 `http://127.0.0.1:8420`。

## Docker 部署

在项目目录运行：

```bash
docker compose up -d --build
```

然后在局域网内打开 `http://<主机局域网 IP>:8420`。停止服务：

```bash
docker compose down
```

该部署没有认证，仅适合可信的局域网环境。

## 装到手机上

手机浏览器里选「添加到主屏幕」。首次联网打开并等待 Service Worker 安装完成后，课程、词卡、语法、听力文本和阅读内容可离线使用。AI 陪练需要网络；朗读和语音识别是否离线可用取决于浏览器及已安装的语音，未缓存的远程字体会回退为系统字体。

离线清单在 `sw.js` 的 `SHELL` 中。新增静态资源时同步清单，发新版时把 `VERSION` 加一；`npm run check` 会校验清单完整性。新版下载完成后，关闭该站点的所有标签页及独立应用窗口再重新打开，以启用新版，不会在练习途中强制刷新。

本机开发默认不启用离线缓存。测试离线功能时，打开 `http://127.0.0.1:8420/?sw=1`，等待安装完成再断网测试。

## 隐私与 AI

- 学习进度、收藏、设置、API 端点和 Key 都保存在当前浏览器的本地存储中。
- 使用 AI 陪练时，对话会直接发送到用户自己配置的 API 端点，DailyGerman 不设中转服务器，也不会集中保存这些内容。
- 导出备份默认不包含 API Key。请勿在公共或不受信任的设备上保存个人 Key。
- 公开版需要 API 服务商允许浏览器跨域请求（CORS）；如果不支持，可改用兼容的代理端点。
- 公开站点用 Google Analytics 统计页面访问量，不涉及学习数据；localhost 不加载。
