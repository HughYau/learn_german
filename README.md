# DailyGerman

> 日常德语，一站就够了。

一款面向中文学习者的开源德语学习网站，从零基础出发，围绕真实生活场景覆盖 A1–B1 的课程、词汇和听说读写练习。

🌐 **在线学习：** <hughyau.com/learn_german/>

## 你可以学什么

- 34 个场景单元、64 节渐进课程
- 740 张课程词卡与间隔重复复习
- 语法手册、实用短语和生活任务
- A1–B1 听力材料与阅读练习
- 每日学习计划、进度记录和数据备份
- 浏览器德语朗读与可选 AI 陪练

## 开始使用

在线版本发布后，直接打开上方网站即可学习，无需注册。学习进度保存在当前浏览器中，也可以在设置页导出备份。

本地运行：

```bash
python server.py
```

然后打开 `http://127.0.0.1:8420`。

## 参与贡献

欢迎提交 Issue 或 Pull Request，帮助改进课程内容、练习设计、界面体验或程序功能。

提交前请运行：

```bash
npm run check
```

该命令会校验课程、词卡、听力、阅读等内容，并运行核心学习逻辑测试。

课程规划详见 [CURRICULUM.md](CURRICULUM.md)。
